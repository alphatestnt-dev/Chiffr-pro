# Chiffr’EcoPro — préparation à la mise en ligne et à la commercialisation

## État actuel

Le site est une application web statique/PWA hébergeable sur GitHub Pages. Le déploiement automatique GitHub Pages est préparé dans `.github/workflows/pages.yml`.

L’accueil validé et les fonctionnalités métier existantes ne doivent pas être modifiés dans cette phase.

## Avant ouverture commerciale

- [ ] Activer/vérifier GitHub Pages sur le dépôt et vérifier le déploiement public.
- [ ] Vérifier l’URL publique, le HTTPS et le fonctionnement mobile/ordinateur.
- [ ] Choisir et raccorder le nom de domaine définitif, si souhaité.
- [ ] Renseigner les informations légales réelles de l’éditeur (identité, forme, adresse, SIREN/SIRET si applicable, contact, directeur de publication et hébergeur selon le statut).
- [ ] Publier des mentions légales adaptées à l’activité réelle.
- [ ] Publier une politique de confidentialité adaptée aux données réellement traitées.
- [ ] Préparer les CGU/conditions commerciales adaptées au modèle retenu.
- [ ] Définir précisément l’offre commerciale, les prix, la facturation, la résiliation et le support avant d’activer un paiement.
- [ ] Choisir un prestataire de paiement adapté et ne jamais stocker directement les données bancaires des clients dans l’application statique.
- [ ] Vérifier les obligations applicables à l’activité et au traitement des données avant commercialisation.
- [ ] Effectuer un dernier smoke test complet après chaque modification de mise en ligne.

## Partenaires écologiques

Les liens vers les sites officiels peuvent rester de simples liens externes. Aucun partenariat, affiliation, remise, recommandation officielle ou validation ne doit être affirmé sans accord écrit.

## Règle de déploiement

Toute modification destinée à la mise en ligne doit préserver l’accueil validé et les fonctionnalités existantes. Aucune nouvelle fonctionnalité métier ne doit être ajoutée uniquement pour préparer l’hébergement ou la commercialisation.

## Informations manquantes volontairement

Aucune identité juridique, adresse, numéro d’immatriculation, tarif ou condition commerciale n’est inventé dans ce document. Ces informations doivent être renseignées à partir des données réelles de l’entreprise avant publication.
